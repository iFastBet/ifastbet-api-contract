# AGENTS.md — ifastbet-api-contract

Канонический контракт между `ifastbet-adminka` и `ifastbet-pocketbase`.

## Границы

- `contract.json` — единственный источник истины для custom REST routes и клиентской PocketBase surface.
- `src/index.js` — импортируемое представление контракта без бизнес-логики.
- `src/check.mjs` и `bin/check.mjs` — адаптеры, проверяющие каждый потребитель только против его собственного кода.
- Пакет устанавливается напрямую из публичного GitHub-репозитория и не публикуется в npm registry.
- Версия 10.0 заменяет scalar outcome/ratio чека упорядоченными `bets`; `stake`/`payout` на чеке остаются общими. Intake принимает одну общую сумму, строки рассчитывает backend. Контракт — `docs/tickets.md` и публичные типы в `src/index.d.ts`. Для локальной реализации потребители используют `file:`, immutable tag ещё не выпущен.

Не добавлять сюда backend implementation, UI logic, секреты или полную внутреннюю схему PocketBase. Публичным должен быть только клиентский контракт.

## Совместимость

- Git tags неизменяемы.
- Breaking changes требуют новой major-версии.
- Добавление совместимой поверхности требует minor-версии.
- Исправление проверяющего инструмента без изменения поверхности требует patch-версии.

## Проверка

```bash
bun run verify
```

Проверка выполняется локально перед созданием tag и push; GitHub Actions в репозитории не используются. После выпуска новой версии отдельно обновлять pinned tag и `bun.lock` в каждом потребителе.
